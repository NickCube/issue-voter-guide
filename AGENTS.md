# Project rules

- Public election pages must show only explicitly verified races, candidates, and source-backed approved claims, because voter-facing data must never rely on generated or unreviewed records.
- Election type and primary presentation must come from structured database fields, because descriptive-text matching is too fragile for civic information.
- Address search must filter verified records by election type and date and never assign district races from town/ZIP guesses; link official ballot lookup when exact coverage is unavailable.
